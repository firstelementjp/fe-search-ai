# 検索UIの設置

FE Search AIは、WordPressページに埋め込めるチャット型検索UIを提供します。2つの表示モードがあり、併用も可能です。

## 埋め込みモード（ショートコード）

投稿、固定ページ、ブロックエディタ内に以下のショートコードを追加します。

```text
[fe-search-ai]
```

後方互換のため、アンダースコア区切りの旧タグ `[fe_search_ai]` も引き続き利用できます。

### テンプレートタグ

テーマのテンプレートでは `fe_search_ai()` テンプレートタグが使えます。同じチャットUIを出力します。

```php
<?php
if ( function_exists( 'fe_search_ai' ) ) {
    fe_search_ai();
}
```

チャットUIは1ページにつき1回のみレンダリングされます。ショートコードとフローティングチャットの両方が出力されそうな場合は重複が抑制されます。

## フローティングチャット

「表示」タブの「フローティングチャットを有効にする」で、サイト全体にチャットバブルを表示できます。表示ルールで以下を制御します。

- ログイン状態（ログインユーザー／未ログイン）
- デバイス（PC／モバイル）
- ページ種別（ホーム、アーカイブ、検索結果、404、詳細ページ）
- 投稿IDごとの include/exclude リスト

フィールドの詳細は[設定](config.md)を参照してください。`fe_search_ai_should_display_chat` フィルターで結果をプログラムから上書きできます。

## 回答が生成される流れ

訪問者が質問を送信すると:

1. 質問がサニタイズされ、基本的なプロンプトインジェクションのパターンがフィルタリングされます（`fe_search_ai_preprocess_user_question`）。
2. 関連チャンクが取得されます — WordPressインデックスのBM25キーワード検索、Qdrantのベクトル検索、またはハイブリッド検索時は両者をRRFで融合。
3. 取得チャンクはフィルタリング可能です（`fe_search_ai_retrieved_chunks`）。有効な場合、内蔵のCohereリランカーがここで動作します。
4. 上位N件のチャンクがチャットプロバイダーに渡され、回答がストリーミングで返されます。

## RESTエンドポイント

チャットUIは公開RESTエンドポイントと通信します。

```text
POST /wp-json/fe-search-ai/v1/stream
```

レスポンスはServer-Sent Events（SSE）で、回答がトークン単位でストリーミングされます。エンドポイントはIP・サイト単位でレート制限され（[設定](config.md)と `fe_search_ai_rate_limit_settings` フィルターを参照）、組み込みのnonceを検証し、パイプライン全体と同じプライバシー前処理を適用します。Pro版では `/query` エンドポイントと外部AIエージェント向けの[MCPサーバー](mcp.md)が追加されます。

## 訪問者向けの機能

チャットウィンドウには独自の設定メニュー（歯車アイコン）があり、訪問者は以下を操作できます。

- 送信キーの変更（Enter／Shift+Enter／Cmd/Ctrl+Enter）— 初期値は「表示」タブの「対話」設定から来ます。
- ブラウザセッションに保存されたローカル会話履歴の消去。
- 入力がどの外部サービスに送られるかの確認（プライバシー通知）。
- Proの同意機能が有効な場合、プライバシー同意の撤回。

## 設置に向いている場所

- ドキュメントのトップページ
- ヘルプセンターやFAQページ
- 製品サポートページ
- ナレッジベース
- 訪問者から質問が多いランディングページ

## 回答品質を調整する

回答が広すぎる、または不正確な場合は、以下を確認してください。

1. 関連コンテンツが同期されているか確認します。
2. 同期対象の設定を見直します。
3. システムプロンプトと「サイトの目的（AI）」を調整します。
4. 必要に応じてリランクを有効化します。
5. 元コンテンツのタイトルや本文を改善します。

よくある問題は[トラブルシューティング](help.md)を参照してください。

## テーマ互換性

標準的なWordPressテーマで動作するよう設計されています。テーマ側のCSSリセットが強い場合は、チャット色やレイアウト設定、カスタムCSSで調整するか、「詳細設定」タブの Assets Loading で同梱CSS/JSを無効化してください。
