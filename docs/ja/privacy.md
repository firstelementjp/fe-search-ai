# プライバシーとデータの取扱い

FE Search AIは、サイト管理者が選択したサービスへデータを送信します。設定画面の**プライバシー**タブでは、現在有効な送信先と保存設定を確認できます。

> プラグインが提供する文面と設定は一般的な叩き台であり、法的助言ではありません。実際の設定、利用者、業種、適用法令に合わせて、サイト管理者の責任で確認してください。

## ゼロデータリテンション（ZDR）の姿勢

FE Search AIは、WordPressサイト自体が訪問者の会話内容を保持しない設計になっています。

- 質問と回答は訪問者へストリーミング配信され、既定の設定では**データベースへ書き込まれません**（Free版・Pro版とも）。
- サーバー側の記録は運用メタデータ（文字数、タイムスタンプ、ハッシュ化された識別子、ランキングスコア、エラーコード）に限定されます。プロンプトや回答テキストを含み得るログペイロードのキーは保存前に除去されます。
- 保持されるすべてのレコード種別に、日次Cronで適用される設定可能な保持期間、管理者による削除アクションがあり、**アンインストール時にデータを削除**が有効な場合はアンインストールで除去されます。
- 同一のマスキング・前処理パイプラインが、チャットUI、Pro版のREST `/query` エンドポイント、Pro版のMCPエンドポイントに適用されます。

**プロバイダー側**のZDR（例：AnthropicやOpenAIがプロンプトと補完を保存しないこと）は、サイト運営者とプロバイダー間の契約上の取り決めです。FE Search AIは、そのような取り決めの対象となり得るリクエスト機能（ストリーミングを用いた標準のMessages / Chat Completions API。バッチ、ファイル、ステートフルなエージェントAPIは不使用）のみを利用しますが、プロバイダーとのZDR有効化は運営者の責任です。一部のAnthropicモデル（Claude Fable 5.1 / 5、Claude Mythos 5.1 / 5などのCovered Models）は30日間のデータ保持が必須でZDR対象外です。ZDR契約に依存する場合は対象モデルを選択してください。

## 回答生成に必要な処理

回答生成のため、訪問者の質問、直近の会話履歴、選択されたサイト内コンテキストが、設定済みチャットプロバイダーへ送信される場合があります。設定によっては、検索処理でEmbeddingプロバイダー、Yahoo! JAPAN 日本語形態素解析API、Cohere Rerank、Qdrantも使用します。

Free版はこの処理を常時通知しますが、チャット利用をブロックしません。Pro版では、チャット開始前にサイトの利用規約への同意を必須にできます。

## ブラウザ内保存

フロントエンドでは、次のデータをブラウザストレージへ保存します。

- ランダムなセッション識別子
- 現在のブラウザセッションの会話履歴
- フィードバック用ログID
- Pro版の同意が有効な場合のバージョン付き同意トークン

訪問者はチャット設定からローカル会話履歴を削除できます。Pro版では同意の撤回も可能です。

## 任意の会話分析

Pro版の管理者は、サービス改善を目的とする任意同意を提示できます。初期状態では無効で、チェックボックスも未選択です。同意しなくてもチャットを利用できます。

管理者と訪問者の双方が有効にした場合でも、保存できるのはPIIおよび禁止ワードをマスクした質問・回答のみです。マスクはベストエフォートであり、適切なプライバシーポリシーやアクセス制御を代替するものではありません。

## 診断用会話概要

診断用会話概要は、任意の会話分析とは別の目的です。初期状態では無効で、Debug Modeと専用設定の両方が有効な場合だけ保存されます。質問・回答本文ではなく、文字数やコンテキスト有無などの運用メタデータを保存します。設定した会話ログ保持期間（既定7日）の経過後に削除されます。

## 同意証跡

Pro版の同意テーブルには、トークンのハッシュ、同意バージョン、選択目的、表示文面のスナップショット、同意・撤回日時を保存します。IPアドレス、User-Agent、セッションID、会話内容は同意テーブルへ保存しません。

撤回済み・旧バージョンの証跡は、設定した保持期間（初期値180日）の経過後に自動削除されます。診断モードまたは分析モードで保存された会話ログは、別の会話ログ保持期間設定（既定7日）に従います。

## プライバシーポリシーへ記載する項目例

サイト固有のポリシーでは、少なくとも次を確認してください。

1. サイト運営者と問い合わせ先
2. 有効なAI、Embedding、形態素解析、Rerank、ベクトルサービス
3. 各サービスへ送信するデータと目的
4. ブラウザ保存とサーバーログ
5. 保持・削除期間
6. 国外移転と委託先の条件
7. 同意撤回・削除依頼の方法
8. 本人または第三者の個人情報・機密情報を入力しないための注意
