# 変更履歴

## 1.1.1 (2026-08-22)

### プライバシーとセキュリティ

- AIプロバイダー呼び出し前に会話履歴をサニタイズし、余分なキーの除去とメッセージ構造の検証を行うようにしました。
- システムログの機密キーフィルタリングを再帰的な削除に変更し、ペイロードフィルターフック後に再適用して機密キーの復元を防止しました。
- Yahoo MAトークン化ログからトークンテキストと単語サンプルを削除し、メタデータのみ残すようにしました。
- インジェクションフィルタのログを入力長とマスク済みサンプルのみ記録するように変更しました。

### 不具合修正

- `date_i18n()` を `wp_date()` に置き換え、同期タイムスタンプ表示のタイムゾーンオフセット問題を修正しました。

### ドキュメント

- 開発者向けフックリファレンスを詳細なテーブルと例で拡充しました。
- DeepWikiのAIドキュメントリンクを追加しました。
- 内部ガイダンスをルール、エージェントガイド、スキールドキュメントへ移行しました。

## 1.1.0 (2026-08-17)

### 検索の可視化

- BM25、Qdrant、RRF、Cohereのスコアを取得できる検索トレースを追加し、ランキング診断をしやすくしました。
- 検索品質の調査に使えるsource countメタデータを検索トレースへ追加しました。
- 古い、または不完全なキーワードインデックスを見つけやすくする同期インデックス健全性メトリクスを追加しました。

### 検索チューニング

- Rerankの品質とパフォーマンスのバランスを調整するhybrid candidate limit設定を追加しました。

### メンテナンス

- オートローダーの互換性と名前空間マッチングを改善しました。
- ドキュメントナビゲーションを改善し、日本語ドキュメントを更新しました。
- CIの依存関係メンテナンスとaudit処理を更新しました。

## 1.0.0 (2026-08-10)

### 検索関連度

- BM25キーワードランキングと単語頻度インデックスを追加し、キーワード検索の関連度を改善しました。
- バッチ同期とリアルタイム同期で、キーワードのトークン数と単語頻度を保存するようにしました。

### 更新と配布

- WordPress.org外で配布されるインストール向けに、GitHub Releasesベースの自動更新を追加しました。
- WordPressがGitHub配布版を更新対応済みとして認識できるよう、`no_update` に対応しました。
- WordPress.org配布へ切り替える際にGitHub更新を無効化できるフィルターを追加しました。

### 同期と管理画面

- フル同期とリアルタイム同期のタイムスタンプを分離し、同期ステータスの表示精度を改善しました。
- APIキー設定にCohere Rerankの参考リンクを追加しました。
- WordPressテーマカラーに合わせて管理画面UIとヘッダーレイアウトを改善しました。

### メンテナンス

- 日本語翻訳とPOTファイルを更新しました。
- WordPress Coding Standardsを3.4.1セキュリティリリースへ更新しました。
- キーワードインデックスとデータベーススキーマ変更のユニットテストを追加・更新しました。

## 0.9.1 (2026-06-11)

### 不具合修正

- 最終同期時刻がUTCではなく正しいローカル時刻で表示されるよう修正しました。
- リリースZIPに不足していたvendor assetsを追加しました。
- 同意ページ警告のJS翻訳を修正しました。

### 開発者向け改善

- LLMへ送信されるコンテキストチャンクのデバッグログを追加しました。
- GitHub Actions、Composer、NPM依存パッケージを更新しました。

### ドキュメント

- ドキュメントを目的別ガイドへ再構成し、ナビゲーションを改善しました。
