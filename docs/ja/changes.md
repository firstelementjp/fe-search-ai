## 1.2.0 (2026-09-30)

### ゼロデータ保持（Zero Data Retention, ZDR）

- 「アンインストール時にデータを削除」が発火しない問題を修正し、プラグインの全テーブル・オプション・トランジェントを対象に拡大
- 「Log Retention (days)」設定が実際に保存され、システムログのローテーションに適用されるよう修正
- 検索トレースの永続化トグル、保持期間設定、削除アクションを追加
- REST・MCPエンドポイントで使用する共通の会話履歴サニタイザーを追加
- プロンプト／回答テキストを含み得るペイロードが保存されないよう、システムログの禁止キーを拡張
- レート制限のIPキーをサイトソルト付きHMAC-SHA256ハッシュへ変更
- 診断用会話ログが回答テキストを送信せず、長さのみを送るよう変更
- プラグインのデータフローを説明するWordPressプライバシーポリシー用の推奨文面を追加
- データ処理マップと外部エンドポイントをドキュメント化

### プライバシー

- プライバシー設定タブと現在のデータ取扱い概要を追加
- 有効なAIサービスとブラウザセッション保存をフロントエンドへ常時表示
- バージョン付き同意連携、同意撤回、ローカル履歴削除、目的別ログモードを追加
- 管理画面の言語がサイト言語と異なるログインユーザーでバージョン付き同意が常に失敗する問題を修正（同意バージョンハッシュから翻訳済みの表示用文字列 `terms_label`・`analytics_label`・recipient `label` を除外）
- 同意バージョンハッシュ仕様の変更に伴い、発行済みの同意トークンは無効となり、訪問者には再度同意を求める表示が出ます

### チャットUI

- オプションメニューを、グループ化されたコントロール・ヘッダー・閉じるボタンを持つ全画面スクロール可能なオーバーレイへ刷新
- Bubble Color にグラデーション対応を追加（開始色・終了色・角度を設定可能）し、固定アニメーションのオンオフも選択可能に。フローティングバブルと送信ボタンへ適用
- Bubble Color 設定をフローティングバブルと送信ボタンへ実際に反映し、ハードコードされていた青〜紫のグラデーションを廃止
- チャット入力欄の背景色を背景色の明度から導出（HSLシフト）するよう変更し、明るい背景色やカスタム色でも入力欄が識別できるように改善
- チャット入力欄の下にフッター通知を追加し、入力エリアをドラッグでリサイズ可能に
- 同意メニュー項目は同意機能が有効な場合のみ表示するよう変更

## 1.1.2 (2026-08-23)

### セキュリティ

- AI生成Markdown HTMLの表示にDOMPurifyサニタイズを導入し、フロントエンドチャットのレンダリングを強化しました。
- 暗号学的に安全な乱数生成を使うチャットセッションIDに変更しました。
- 回答内リンクから安全でないURLスキームを除去し、フロントエンドのリンク安全性を改善しました。
- GitHub Actionsワークフローの権限をread-onlyのcontentsアクセスに制限しました。

### ビルドとリリース

- DOMPurifyをリリース用アセットビルドとフロントエンドスクリプト依存関係に追加しました。
- プラグイン承認後に明示的に有効化するまで、WordPress.org SVNデプロイを無効化しました。
- DOMPurifyのフロントエンド依存関係を確認するユニットテストを追加しました。

## 1.1.1 (2026-08-22)

### プライバシーとセキュリティ

- AIプロバイダー呼び出し前に会話履歴をサニタイズし、余分なキーの除去とメッセージ構造の検証を行うようにしました。
- システムログの機密キーフィルタリングを再帰的な削除に変更し、ペイロードフィルターフック後に再適用して機密キーの復元を防止しました。
- Yahoo MAトークン化ログからトークンテキストと単語サンプルを削除し、メタデータのみ残すようにしました。
- インジェクションフィルタのログを入力長とマスク済みサンプルのみ記録するように変更しました。

### 不具合修正

- `date_i18n()` を `wp_date()` に置き換え、同期タイムスタンプ表示のタイムゾーンオフセット問題を修正しました。

### ドキュメント

- 開発者向けフックリファレンスを詳細なテーブルと例で拡充しました。
- DeepWikiのAIドキュメントリンクを追加しました。
- 内部ガイダンスをルール、エージェントガイド、スキールドキュメントへ移行しました。
