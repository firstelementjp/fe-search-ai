# ライセンスとPro

FE Search AIは無料プラグインとして完全に動作します。FE Search AI Proは別のアドオンプラグインで、ライセンスキーにより高度な機能を解放します。

## Proのインストール

1. 無料版の FE Search AI をインストールして有効化します。
2. ProアドオンのZIPを **プラグイン → 新規追加 → プラグインのアップロード** からインストールし、有効化します。
3. FE Search AI の設定画面に「ライセンス」タブが表示されます。

## ライセンスの有効化

「ライセンス」タブで:

1. **Pro License Key** フィールドにライセンスキーを貼り付けます。**Show** ボタンで保存済みキーを表示できます。
2. 有効化を実行すると、FirstElementのライセンスサーバー（`download.firstelement.co.jp`）でキーが検証されます。

有効な場合、タブにはライセンス状態、有効期限（残り日数付き）、アクティベーション数が表示されます。**Deactivate** ボタンでアクティベーションを解放し、キーを別サイトへ移行できます。

ライセンスキーは暗号化して保存されます。ライセンス検証ではサイトURLとキーのみがライセンスサーバーに送られ、訪問者データは含まれません。詳しくは[プライバシーとデータの取扱い](privacy.md)を参照してください。

## Proで追加される機能

| 領域         | Proの機能                                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| プロバイダー | 追加プロバイダー（DeepSeek、Qwen予定）、OpenAI互換カスタムエンドポイント（ローカルLLM、BGE埋め込み）、フェイルオーバー（予定）         |
| モデル       | プロバイダーごとのモデル選択（埋め込みモデル含む）                                                                                     |
| 同期         | カスタムフィールドのインデックス化、ストップワード編集                                                                                 |
| プロンプト   | プロバイダーごとのカスタムプロンプト                                                                                                   |
| 表示         | 全画面チャットページ、利用規約・プライバシーへの訪問者同意                                                                             |
| セキュリティ | [禁止ワードのマスキングとレート制限](config.md#セキュリティpro)                                                                        |
| 詳細設定     | AIエージェント向け[MCPサーバー](mcp.md)、外部クライアント用APIトークン管理（`/query` エンドポイント）、CSVエクスポート付き詳細会話ログ |

ライセンスが有効な場合、設定画面に「モデル」「セキュリティ」タブが追加され、既存タブにもPro専用フィールドが挿入されます。

## ライセンスのトラブルシューティング

- **「Pro is not installed or activated」** — ライセンス管理にはキーだけでなくProアドオンプラグインが必要です。
- **有効化に失敗する** — `download.firstelement.co.jp` への外部HTTPSアクセスと、キーに残っているアクティベーション枠を確認してください。
- **サーバー移行後にライセンスが無効になる** — 新しいサイトでキーをDeactivateしてから再度Activateしてください。
